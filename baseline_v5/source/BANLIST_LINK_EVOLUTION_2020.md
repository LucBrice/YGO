# Référence banlist — Yu-Gi-Oh! Legacy of the Duelist: Link Evolution (mise à jour 24 mars 2020)

## But de ce fichier

Ce fichier est une **référence de projet** pour toutes les demandes de decks, FTK, OTK, loops, locks et combos dans **Yu-Gi-Oh! Legacy of the Duelist: Link Evolution**.

Quand l'utilisateur demande un deck sans préciser une autre époque :

1. utiliser le **pool de cartes de Link Evolution** ;
2. raisonner avec la **banlist interne de la version finale 2020** ;
3. vérifier les ratios avant de proposer la decklist ;
4. ne jamais proposer 2 ou 3 copies d'une carte Limitée ;
5. distinguer clairement un deck **banlist-legal** d'un deck **Forbidden / solo fun**.

---

## Quelle banlist utilise Link Evolution ?

Après la mise à jour du **24 mars 2020**, Link Evolution utilise une liste de type **World Championship Format** basée sur les listes **TCG du 20 janvier 2020** et **OCG du 1er janvier 2020**.

Principe pratique : lorsqu'une carte a des restrictions différentes entre TCG et OCG, Link Evolution tend à retenir **la restriction la plus sévère**.

Exemple :

- carte illimitée en TCG mais Limitée en OCG → **Limitée** dans Link Evolution ;
- carte Limitée en TCG mais Interdite en OCG → **Interdite** dans Link Evolution.

Il existe quelques particularités propres au jeu ; **Thunderclap Skywolf** est notamment signalé comme Interdit malgré son statut inhabituel.

> Important : la banlist est surtout imposée pour les duels en ligne. En solo/campagne, le jeu permet d'utiliser des cartes interdites. Pour ce projet, on considère néanmoins par défaut que les decks proposés doivent respecter la banlist, sauf demande explicite de « Forbidden Mode ».

# Règle de validation pour ChatGPT dans ce projet

Avant de donner une decklist Link Evolution :

1. compter exactement **Main Deck / Extra Deck / Side Deck** ;
2. contrôler chaque carte proposée contre cette référence ;
3. si une carte est Limitée, ne jamais en mettre plus de 1 ;
4. si une carte est Semi-Limitée, ne jamais en mettre plus de 2 ;
5. si une carte est Interdite, ne pas l'inclure dans une liste « légale » ;
6. si une combo historique exige une carte interdite, la présenter comme **Forbidden Mode / solo fun** ;
7. ne pas utiliser automatiquement la banlist TCG 2026, Master Duel ou une autre banlist moderne ;
8. en cas de conflit entre cette note, un guide externe et **l'icône de restriction affichée dans le deck builder du jeu**, l'affichage du jeu est la référence finale.

## Note de prudence

Link Evolution utilise une liste hybride et non une simple copie exacte de la TCG ou de l'OCG. Certaines cartes ont donc un statut surprenant. Cette note est destinée à empêcher les erreurs de construction les plus fréquentes et à forcer une **vérification explicite des restrictions** lors de chaque future decklist.

## Audit exhaustif 2026-09-21

Comparaison complète effectuée contre les listes sources servant à la banlist Link Evolution finale : TCG 20 janvier 2020 + OCG 1er janvier 2020, avec application de la restriction la plus sévère et particularité propre au jeu déjà documentée (Thunderclap Skywolf).

Corrections appliquées :
- Interdites ajoutées : Gandora-X the Dragon of Demolition ; Double Iris Magician ; Wind-Up Carrier Zenmaity.
- Limitées ajoutées : Luster Pendulum, the Dracoslayer ; Sky Striker Ace - Kagari ; Mask Change II ; Reasoning.
- Necroface corrigé : Semi-Limitée → Limitée.
- Semi-Limitée ajoutée : Trickstar Candina.

Comptes après correction : 108 Interdites ; 103 Limitées ; 18 Semi-Limitées ; 229 cartes restreintes uniques.
